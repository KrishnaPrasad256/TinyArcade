# TinyArcade
A mini handheld game console with an ESP32-C3.

### Project Componenets
- SSD1306 OLED Display x1.
- Button Swtches x5.
- Slide Switch x1
- Buzzer x1.
- ESP32-C3 x1.
- Perfboard x1
- Li-Po cell x1
- TP4056 Module x1
- 5v Boost Module x1
- AMS1117 LDO voltage regulator x1

### Games
- Tetris
- DDR
